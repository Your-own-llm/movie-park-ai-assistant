# Movie Park AI Production Assistant

Concept demo for an AI-assisted production inquiry workflow.

## Demo flow

Landing → AI Assistant → Project Brief → Portfolio Matching → Account Manager Dashboard → Inquiry Details

## Phase 1

This version is a dependency-free frontend prototype using local browser state. It does not connect to Movie Park internal systems or external AI services.

## Planned integrations

- CrewAI orchestration
- AnythingLLM knowledge/RAG
- Firecrawl research
- Pipecat voice interface
- CRM/email/database integrations
